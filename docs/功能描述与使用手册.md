# StackChan-Newstep 功能描述与使用手册

> 对应 PRD 交付物 D-2《操作手册》。面向使用者：说明设备能做什么、怎么操作、出问题怎么办。
> 标有「待实测」的指标在验证机冒烟后回填（见 [验证机编译验证说明.md](验证机编译验证说明.md)）。

## 1. 功能全景

| # | 功能 | 入口 | 一句话说明 |
|---|---|---|---|
| 1 | 云端 AI 语音对话 | 唤醒词 | 离线唤醒 → 小智云端流式 ASR/LLM/TTS 对话，可打断 |
| 2 | 表情与摄像头跟随 | 开机即用 | 程序化 Avatar 表情 + 云台自动跟随面前的人脸 |
| 3 | 触控互动 | 机身/屏幕 | 摸头、手势、摇晃、抱起 → 语料+表情+舵机+LED |
| 4 | 红外家电遥控 | **双指触摸屏幕** | 学习遥控器编码并发射，完全离线 |
| 5 | 语音联动控制家电 | 对话语音 | 「打开客厅空调」→ 云台对准 → 红外发码 → 反馈 |
| 6 | 拍照问答 | 对话语音 | 「看看我在干嘛」→ 拍照给 LLM 看图回答 |
| 7 | 设备管理 | 语音/MCP | 音量、亮度、主题、LED 灯色、OTA 升级、电量提醒 |
| 8 | 早安问候 | 定时 | 工作日早上定时问候（需联网） |

## 2. 首次使用

1. **开机**：长按电源键；首次开机进入配网模式（屏幕显示热点名与配置地址）
2. **配网**：手机连接设备热点 → 浏览器打开配置页 → 填入 2.4G WiFi 信息
3. **绑定云端**：配网后自动连接小智云端（xiaozhi.me 或自建服务器），必要时按提示完成激活
4. **验证对话**：说唤醒词「**土豆土豆**」→ 听到回应即正常

## 3. 语音对话

| 操作 | 方法 |
|---|---|
| 唤醒 | 说「土豆土豆」（阈值可调，见 §8 故障排查） |
| 对话 | 唤醒后直接说内容，自动聆听（AutoStop）/播报 |
| 打断 | 说话时再喊「土豆土豆」即可打断并重开聆听 |
| 开关对话 | 单击屏幕（触摸屏）或语音指令 |
| 拍照问答 | 说「看看我在干嘛」「这是什么」→ 摄像头拍照 → LLM 看图回答 |

**支持的部分指令**（其余自由对话）：
「把音量调到 50」「屏幕亮一点」「换成深色主题」「把灯调成红色」「升级固件」

## 4. 触控与姿态互动

### 4.1 屏幕手势（FT6336）

| 手势 | 动作 | 反馈 |
|---|---|---|
| **单击** | 短按（<0.5s，位移小） | 开关对话（未配网时进入配网） |
| **双击** | 0.5s 内两次单击 | 「主人戳了戳土豆的脸」 |
| **长按摸头** | 按住 ≥1.5s 并轻微移动 | 爱心表情+歪头+「主人摸了摸土豆的头」 |
| **上滑/下滑/左滑/右滑** | 快速滑动（≥20px） | 随机语料（弹脑门/摸腹肌/捧脸/捏后颈等） |
| **双指触摸** | 两指同时按下 | **打开红外遥控屏** |

### 4.2 头顶三区触摸（SI12T）

任意区域摸头 → 爱心表情 + 舵机歪头 + 随机回应（5 秒冷却，7 条文案轮换）。

### 4.3 姿态检测（BMI270）

| 动作 | 触发条件 | 反馈 |
|---|---|---|
| 摇晃 | 1 秒内 2 次晃动尖峰 | 「主人摇了摇土豆」 |
| 抱起 | 持续拿起 0.5s | 「主人把土豆举起来」 |

> 互动触发后 5 分钟冷却，期间不重复触发。

## 5. 表情、跟随与灯光

- **Avatar 表情**：约 21 种情绪随对话与互动变化（开心/难过/生气/思考/亲亲…），带眨眼、呼吸、说话嘴型
- **人脸跟随**：摄像头检测面前移动目标，云台平滑跟随（左右 ±45°、上下 5-60°）；**对话中跟随、待机时扫视**
- **情绪灯（12 颗 WS2812）**：

| 状态 | 灯色 |
|---|---|
| 说话 | 橙色 |
| 聆听 | 绿色 |
| 待机 | 灭 |
| 红外学习 | 蓝色常亮 |
| 红外成功 | 绿色闪烁 |
| 红外失败 | 红色闪烁 + 屏幕通知 |

## 6. 红外家电遥控

### 6.1 打开遥控屏

**双指同时触摸屏幕** → 进入「红外遥控」界面（左上角「返回」退出）。

### 6.2 学习新码

1. 点「**＋ 学习新设备**」→ 或进入已有设备
2. 点**灰色按键**（未学习）→ 状态栏提示「请对准遥控器按按键…」
3. 10 秒内用**原装遥控器**对准设备红外接收窗按对应按键
4. 捕获成功 → 状态显示「已保存 xx」，按键**变绿**
5. 学习超时 → 状态提示「学习超时，请重试」

### 6.3 发射

点**绿色按键**即发射对应红外码（设备对准家电方向效果最佳，距离建议 ≤3m，待实测）。

### 6.4 预设按键

| 按键 | 存储名 | 说明 |
|---|---|---|
| 电源 | power | 开关机 |
| 温度+ / 温度- | temp_up / temp_down | 空调调温 |
| 模式 | mode | 制冷/制热等模式切换 |
| 风速 | fan_speed | 风速档位 |
| 摆风 | wind_swing | 扫风开关 |
| 定时 | timer | 定时功能 |
| 静音 | mute | 静音键 |

> 码库持久化保存（重启不丢）；支持 JSON 导入导出（开发/备份用）。

### 6.5 学习中的小提示

- 红外接收窗口在设备正面，遥控器对准机身前部
- 短按按键即可，**不要长按**（长按会产生重复帧，首次学习建议短按）
- 部分空调遥控器需"对准再按"，学习失败请调整距离（30cm~1m 为宜，待实测）

## 7. 语音联动控制家电

| 你说 | 设备执行 |
|---|---|
| 「打开客厅空调」 | 云台转向空调方位 → 发射电源码 → 绿闪+点头+语音反馈 |
| 「把空调调到 25 度」 | LLM 调用红外工具发温度码（需已学习 temp 类按键） |
| 「关掉电视」 | 发射电视电源码 |
| 「记下空调的位置」 | 云台转到当前角度，保存为该设备方位预设 |
| 「帮我学一下遥控器」 | 提示使用机身学习界面 |

**工作链路**：语音 → LLM 语义理解 → `self.servo.pan`（对准）→ `self.ir.send`（发码）→ LED/表情/语音反馈。

**注意**：
- 联动依赖云端 LLM，**断网时不可用**；但遥控屏发射完全离线可用
- 新学习的设备/按键**重启后** LLM 才认识（工具描述开机生成）
- 发码瞬间摄像头跟随会短暂暂停（<1s，防电磁干扰），属正常现象

## 8. 常见故障排查

| 现象 | 排查 |
|---|---|
| 唤醒不灵/误唤醒 | 调整 `sdkconfig.defaults` 的 `CONFIG_CUSTOM_WAKE_WORD_THRESHOLD`（越小越灵敏；生僻词需更低阈值） |
| 红外学习超时 | ① 遥控器是否对准机身前部；② 距离 30cm~1m；③ 是否短按；④ 原装遥控器电池 |
| 发射后家电无反应 | ① 确认按键**已变绿**（已学习）；② 家电方向与距离；③ 家电协议是否 NEC 系（首期仅支持 NEC/NEC-ext，Sony/RC-5 暂不支持） |
| 遥控屏打不开 | 双指需**同时**触摸屏幕，间隔过大可能识别为两次单击 |
| 语音联动无效果 | ① 断网（遥控屏仍可用）；② 设备/按键未学习或未重启；③ 云端 LLM 未开启 MCP 工具 |
| 自定义灯光后需重启 | 换灯色后偶发需拔 USB 断电 30s 重启（已知问题，换色不频繁影响不大） |
| 电池供电开机困难 | 负载大时插 USB 再开机（已知问题） |
| 低电量 | ≤15% 未充电时：表情变难过 + 语音提醒「我快没电了」，请及时充电 |
